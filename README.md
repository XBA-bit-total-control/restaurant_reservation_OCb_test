# Table booker

REST API на FastAPI для бронирования столиков в ресторане. Через `/api/bookings` можно создать бронь, получить список с фильтром по дате, найти бронь по ID и отменить её. Данные хранятся в локальной SQLite через SQLAlchemy.

## Запуск

Понадобятся Python 3.11 или новее и uv.

Выполните из корня проекта:

```powershell
uv run uvicorn app:app --app-dir src/restaurant_reservation
```

При первом запуске приложение создаст `bookings.db` в корне проекта. Swagger UI доступен по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

## Тесты

Запустить все тесты из корня проекта:

```powershell
uv run pytest -p no:cacheprovider
```

Тесты используют общую SQLite-базу в памяти. Запускать Uvicorn отдельно не требуется.

## Создание и примечания:

1) Решено было создать свой отображаемый пример тела запроса в Swagger для создания брони. 
Так он имел не корректное отображение минут, что при реальном запросе недопустимо.
2) Чтобы ограничить перехватываемые ошибки в представлениях и отличить их от других был создан
отдельный модуль exceptions.py с 2-мя классами ошибок.
3) Структура приложения разделена на разные модули для удобства и быстрой ориентации.
4) По улучшению, если бы было больше времени, то я бы добавил поиск bookings по диапазону дат; добавил бы то, что не
требуется по заданию, регистрацию, аутентификацию и если бы были администраторы, то и авторизацию, чтобы можно было ограничить доступ к API
и иметь структурированную информацию о клиентах.
Также можно было бы добавить уведомление на почту клиентам, которые хотели забронировать столик, но он оказался занят, а после освободился.
При условии, что почта нам известна.
5) Ещё сделал бы логирование и большее покрытие тестами.
